# Stamp Tool for Krita
- It is a Krita Plugin made using Python that allows users to use built-in stamps, add custom stamps, choose size, rotate and use patterns on canvas.

## How to install it?
1. Download/Clone 'StampTool.zip' from this repository.
2. Open Krita.
3. Go to **Tools > Scripts > Import Python Plugin from file**
4. Select 'StampTool.zip'.
5. Restart Krita.
6. Go to **Settings > Configure Krita > Python Plugin Manager**.
7. Find **Stamp Tool** and make sure it is enabled.
8. Restart Krita again.
9. Create a new file/canvas then Open the plugin from **Tools > Scripts > Stamp Tool**.

The Stamp Tool dialog will appear, and the plugin is ready to use!!
